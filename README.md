# IAM-SOC-Analytics-Lab

## Project Overview

IAM-SOC-Analytics-Lab is a hands-on portfolio project designed to simulate the responsibilities of an Identity and Access Management (IAM) Analyst, Security Operations Center (SOC) Analyst, and Data Analyst.

The project combines SQL, Python, SQLite, Power BI, and documentation to investigate user identities, security groups, login activity, help desk tickets, and security incidents in a simulated enterprise environment.

Rather than focusing only on writing SQL queries, this repository demonstrates a complete analyst workflow—from identifying a business problem to documenting findings and making recommendations.

---

## Goals

- Practice enterprise SQL investigations
- Learn Identity and Access Management (IAM) concepts
- Perform SOC-style security investigations
- Build executive reporting and dashboards
- Automate reporting using Python
- Develop professional documentation and analyst workflows
